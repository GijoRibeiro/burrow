# Workspace fonts

Bundled locally from Google Fonts so native and browser workspaces work offline.

- DM Sans (variable, optical size and weight): https://github.com/google/fonts/tree/main/ofl/dmsans
- Google Sans Code (variable weight, regular and italic): https://github.com/google/fonts/tree/main/ofl/googlesanscode

The corresponding SIL Open Font License files are included in `web/public/font-licenses/` and copied into each production build.
Gridbit and PixelPurl remain for the separate legacy dashboard.
